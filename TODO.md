## 4. Известный долг и ограничения

- `AGENTS.md` (разделы 8, 15, 22) говорит, что реальные выгрузки не коммитятся, а `dataset/output/utility-rating.json` отслеживается по прямому решению владельца; регламент по решению владельца не меняется.
- У frontend есть технический исходящий доступ через сеть `edge`: Docker не публикует порт контейнера только во внутренней сети.
- Журналы в томах не ротируются.
- Healthcheck и гейт фронта пишут `API_READY` / `SNAPSHOT_CACHE_HIT` на каждый вызов — шум в журнале api.
- Шрифт Arial для рендера берётся из Windows: лицензия на использование в растровой подложке не проверена, байт-в-байт повтор требует тех же файлов шрифтов.
- Одна растровая подложка мылится на крупных зумах; полноценная slippy-карта с тайлами — отдельное решение владельца (раздел 6).
- `packaging` используется в тестах как транзитивная зависимость pytest, явно не указан.
- Полноту транзитивных пинов `constraints.txt` сторож не доказывает (без резолвера).
- Таблица переменных окружения в README не упоминает, что `DOMDOSSE_LOG_*` читают также legacy и map.
- Весь manifest карты попадает в JS-бандл; поле `PILOT_MAP.crs` читают только тесты.
- Fixtures `frontend/src/test/dossierFixtures.ts` частично дублируют помощники `HousesPage.test.tsx`.
- Когда кнопка «Показать ещё» исчезает, фокус клавиатуры уходит на `body` — вернуть фокус на список событий.
- В сообщениях ошибок валидации `frontend/src/features/dossier/api.ts` и `frontend/src/lib/api.ts` осталось слово «пилот» (в интерфейс не выводится).
- Период показывается «– 13 нояб.», хотя окно полуоткрытое и последний учтённый день — 12 ноября (сделано по образцу владельца).
- Однократно наблюдался старт карты на зуме 17: исправлено вписывание только при измеренном контейнере, причина не доказана.
- AGENTS.md §6 п.5 всё ещё требует связывать худшую категорию с ограничением рейтинга в интерфейсе — расходится с решением владельца (регламент не трогаем).
