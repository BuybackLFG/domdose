## 5. Известный долг и ограничения

### Регламент и данные
- `AGENTS.md` (разделы 8, 15, 22) говорит, что реальные выгрузки не коммитятся, а
  `dataset/output/utility-rating.json` отслеживается по прямому решению владельца;
  регламент по решению владельца не меняется.
- `AGENTS.md` §6 п.5 требует связывать худшую категорию с ограничением рейтинга в
  интерфейсе — расходится с решением владельца (регламент не трогаем).
- Push в `wip/compose` — разовое решение владельца вопреки §22; при публичном репозитории
  датасет станет публичным.

### Инфраструктура
- У frontend есть технический исходящий доступ через сеть `edge`: Docker не публикует
  порт контейнера только во внутренней сети.
- Журналы в томах не ротируются.
- Ворота SPA делают подзапрос `/api/ready` на каждый документный запрос: в журнале api
  строки `API_READY` / `SNAPSHOT_CACHE_HIT` на каждую загрузку страницы и healthcheck; при
  битом датасете api на каждом запросе заново читает файлы и вызывает scoring.
- При остановленном `api` запрос `/api/*` получает 504 страницы Nginx без
  `X-DomDossier-Error`.
- Не проверены эмпирически: ветка «ворота пропустили, но статика ответила 500»; формат
  `$upstream_status` при нескольких репликах api; healthcheck и `depends_on` в реальном
  `docker compose up` (будет в приёмке).
- `packaging` используется в тестах как транзитивная зависимость pytest, явно не указан.
- Полноту транзитивных пинов `constraints.txt` сторож не доказывает (без резолвера).
- Таблица переменных окружения в README не упоминает, что `DOMDOSSE_LOG_*` читают также
  legacy и map.

### Карта
- Шрифт Arial для рендера берётся из Windows: лицензия на использование в растровой
  подложке не проверена, байт-в-байт повтор требует тех же файлов шрифтов.
- Растровая подложка ограничена зумом 14; полноценная slippy-карта с тайлами — отдельное
  решение владельца (раздел 6).
- На обзорном уровне подписано только 5 улиц; в центре на детальном уровне густая сеть
  проездов; подписи бухт частично заходят на сушу.
- Мультиполигоны, обрезанные границей выгрузки PBF, не собираются; экстракция требует
  около 2 ГБ RAM и 4–5 минут.
- Весь manifest карты попадает в JS-бандл; поле `PILOT_MAP.crs` читают только тесты.
