# Датасет коммунальных отключений

В этой папке находится самостоятельный комплект для внешней модели:

* `COLLECTION_PROMPT.md` — полное задание сбора;
* `utility-rating-dataset.schema.json` — strict JSON Schema 2020-12;
* `output/utility-rating.json` — итоговый датасет, создаваемый после сбора.

## Контур MVP

Для расчёта используется пилотная выборка из 20 домов: по 4 в Ленинском, Первомайском,
Первореченском, Советском и Фрунзенском районах. Среднее относится только к этой выборке,
а не ко всему Владивостоку. Ограничение передано внешней модели отдельно; базовый текст
задания по решению владельца не изменяется.

## Запуск сбора

1. Передай внешней модели содержимое `COLLECTION_PROMPT.md`.
2. Подставь в тексте фактические значения `{{WINDOW_START}}` и `{{WINDOW_END}}`
   с точной разностью 30 суток и смещением `+10:00`.
3. Не проси модель сочинить недостающие данные. Если полный городской справочник или
   покрытие категории недоступно, она обязана вернуть честный `incomplete`-результат.

Итоговый JSON сохраняется по пути:

```text
C:\Progg\Development\ДомДосье2\dataset\output\utility-rating.json
```

Если внешняя модель не имеет доступа к файловой системе, оператор сохраняет её единственный
JSON-ответ по этому пути без Markdown-ограждений и дополнительного текста. Существующий файл
не перезаписывается новым прогоном без отдельного подтверждения владельца.

`dataset/output/*.json` исключён из Git: собранные реальные выгрузки не коммитятся. Промпт,
схема и эта инструкция находятся под версионным контролем.
